Checksum Verifier

Pick a file, paste the hash you were given, and confirm they match — before you trust or run the file.

Drop a file here, or click to browse
The file is hashed in your browser and never leaves this device
⚠️ SHA-1 is cryptographically weak. Use only for accidental corruption checks, not for verifying software authenticity.
Uses the browser's built-in Web Crypto API. No network request is made with your file or its hash. The whole file is read into memory to hash it, so very large files can be slow or, past a point, fail outright.
